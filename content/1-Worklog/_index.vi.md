# Nhật ký 8 tuần

Nhật ký ghi lại mục tiêu, hoạt động AWS managed, kết quả kỹ thuật đã xác minh, vấn đề, quyết định, tham chiếu minh chứng và bước tiếp theo trong thời gian thực tập từ 15/06/2026 đến 15/08/2026.

| Tuần | Trọng tâm |
|---:|---|
| 1–2 | Nền tảng AWS, thiết kế dữ liệu, tiền xử lý managed |
| 3–4 | Huấn luyện, HPO, đánh giá, Model Registry |
| 5–6 | Endpoint, API Gateway và Lambda |
| 7–8 | Data Capture, drift monitoring, Pipeline và báo cáo |
